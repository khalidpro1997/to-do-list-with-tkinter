# 📝 Tkinter To-Do List App

A simple GUI To-Do List application built with Python and Tkinter.

## Features

- ✅ Add tasks
- ❌ Delete selected tasks
- 💾 Save tasks to a text file
- 📂 Load tasks from a text file

## Getting Started

### Requirements
- Python 3.x

### How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/todo-tkinter.git
cd todo-tkinter

Run the app
python todo_app.py
